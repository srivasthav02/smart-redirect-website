# Smart Redirect Website

## Overview
A single page that links to many AI and productivity tools, with search and category filters.

## Features
- Live search and category filter
- Add tools by editing the `TOOLS` array in `script.js`
- Responsive, keyboard accessible

## Tech Stack
HTML, CSS, JavaScript

## How to Run
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main branch) to host it free.
